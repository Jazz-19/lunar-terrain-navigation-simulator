# Project Results

This directory contains photographs, visual outputs and demonstration recordings from the Autonomous Lunar Terrain Navigation Simulator.

## 1. Hardware Setup

`hardware-setup.jpeg`

Photograph of the Raspberry Pi 3 development setup used during the project demonstration.

## 2. Navigation Demonstrations

The simulator processes lunar terrain images and generates navigation decisions based on the identified candidate safe regions.

### LEFT Navigation
`left-steering-demo.jpeg`

Demonstration of the system generating a LEFT steering command.

### STRAIGHT Navigation
`straight-navigation-demo.jpeg`

Demonstration of the system generating a STRAIGHT navigation command.

## 3. Project Demonstration Video

`navigation-demo.mp4`

Recorded demonstration showing the image-processing pipeline and navigation commands.

## 4. Navigation Commands

The implemented navigation logic generates four possible outputs:

- Drive STRAIGHT
- Steer LEFT
- Steer RIGHT
- STOP

## Note

The photographs and video document the project setup and software demonstration. The navigation decisions are based on image-processing heuristics and represent simulated navigation guidance rather than physical rover movement.
