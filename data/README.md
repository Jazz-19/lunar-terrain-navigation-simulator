# Dataset Documentation

## Dataset Source

The lunar terrain navigation project uses the following publicly available Kaggle dataset:

**Dataset:** LU3M6TGT

**Source:** https://www.kaggle.com/datasets/riccardolagrassa/lu3m6tgt

## Dataset Information

The dataset is used as a source of lunar surface imagery for developing and evaluating computer vision techniques.

The complete dataset is approximately 512 MB and is maintained separately from this GitHub repository.

## Download Instructions

1. Visit the Kaggle dataset link above.
2. Download the dataset.
3. Extract the archive.
4. Follow the project instructions to configure the dataset path.

## Demonstration Images

Five selected images are included in the `Images/` directory for demonstration purposes.
